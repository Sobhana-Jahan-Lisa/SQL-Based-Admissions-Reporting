# Report Descriptions

This document explains the operational reports included in the project.

## 1. Applicants by Program

Shows the number of applicants in each graduate program and degree level. This report can help admissions staff understand application volume by program.

## 2. Application Status Summary

Counts applications by status, such as Submitted, Incomplete, Under Review, Admitted, Denied, and Waitlisted.

## 3. Incomplete Applications

Lists applicants whose application status is marked as Incomplete. This report can support follow-up communication and application-cycle preparation.

## 4. Missing Documents

Identifies applicants who are missing required or optional documents such as transcripts, recommendation letters, or English proficiency materials.

## 5. Reviewer Workload

Shows the number of applications assigned to each reviewer. This report can help balance workload among faculty reviewers, administrative reviewers, and committees.

## 6. Monthly Submission Trends

Counts applications submitted each month. This report can help identify peak application periods.

## 7. International vs Domestic Applicants

Summarizes the number of domestic and international applicants.

## 8. Average Processing Time

Calculates the average number of days between submission and decision by program.

## 9. Export-Ready Applicant Records

Creates a clean applicant export that includes applicant identity, program, term, status, reviewer, GPA, and decision information.
